# 🌸 NUVIA — Period Care

> Modern period care, everyday comfort, and thoughtfully designed menstrual essentials.

NUVIA is a modern period-care storefront concept focused on making everyday menstrual essentials feel **comfortable, clear, discreet, and thoughtfully designed**. The brand combines a soft contemporary visual identity with an organized shopping experience for period products, care kits, travel essentials, and everyday comfort.

---

## ✨ Brand Philosophy

NUVIA is built around a simple idea:

**Period care should feel normal, comfortable, accessible, and easy to understand.**

The storefront avoids an overly clinical presentation and instead uses a calm, modern visual language with:

- Soft lavender
- Warm white
- Blush pink
- Mauve
- Berry accents
- Clean typography
- Gentle editorial photography
- Clear product information
- Discreet shopping language

## 📸 Photography Direction

NUVIA uses clean, realistic product photography.

Product images should be:

- High quality
- Well lit
- Individually framed
- Properly centered
- Fully visible
- Free from website screenshots
- Free from prices or interface elements
- Free from watermarks
- Free from unrelated products
- Consistent in presentation

Different products should use **different photographs whenever possible** to avoid a repetitive catalog.

## 🌐 GitHub Pages

The project is intended to work with GitHub Pages as a static website.

Recommended deployment process:

1. Create a public GitHub repository.
2. Upload the project files.
3. Confirm `index.html` is located at the repository root.
4. Open repository **Settings**.
5. Open **Pages**.
6. Select the deployment branch.
7. Save the configuration.
8. Wait for GitHub Pages to publish the site.
9. Test the published URL on desktop and mobile.
